# signature-filtering

Local working repo for Martingale prep track B2: the Kalman–Bucy filter as a linear functional of the signature of the time-augmented observation path, and truncation-error rates.

- `notes/kalman_bucy_signature.tex`: derivation skeleton (proof written by Tam).
- `results/`: D2 numerical verification outputs (to come).

The exact representation is known: Cohen et al. (2023), *Nowcasting using regression on signatures*, arXiv:2305.10256, Thm 1. The open question pursued here is the truncation error.
